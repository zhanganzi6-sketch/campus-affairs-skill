# 事项台账与截止提醒规则（ledger-guide）

## 数据与安全

- 台账数据文件为 `校务台账.json`，保存在**用户当前工作目录**（跨会话持久保留）。
- 所有台账操作（登记/查看/更新/完成/删除）必须通过 `scripts/ledger_manager.py` 执行，不手改 JSON。
- 脚本在当前工作目录运行（先切换到用户工作目录，再以完整路径调用脚本），确保数据文件位置一致。
- 删除（`rm`）与手工清空属于破坏性操作：执行前向用户复述将删除的条目并取得确认。
- 台账属于用户个人数据：内容包含学业与办事安排，不写入任何对外交付物，不回写进技能知识库。

## 字段语义

| 字段 | 说明 |
|---|---|
| 事项 | 名称，如"奖助学金申报" |
| 截止日期 | YYYY-MM-DD；相对日期（"下周五"）先换算成绝对日期再录入 |
| 状态 | 待启动 → 材料准备中 → 已提交 → 待领取结果 → 已完成；特殊情况：已取消 |
| 对接部门 | 辅导员/院系/处室，用于过期后求助 |
| 材料清单 | 顿号或逗号分隔；数量影响准备时长估算 |
| 备注 | 补充约定、提交方式等 |

## 提醒节奏

1. **登记时**：立即输出截止日倒计时 + 建议最迟启动日期（脚本自动计算）。
2. **主动查询时**：用户询问"我有什么要办的/最近有什么截止"，运行 `upcoming`（默认 7 天，可按用户口径调整 `--days`）。
3. **定时提醒**（如运行环境可用 scheduler 技能/定时任务工具）：登记截止日较远的事项后，主动建议在**截止前 7 天、3 天、1 天**分别设置提醒，征求用户同意后再创建；环境不支持定时任务时，改为在每次相关对话中口头提示剩余天数。
4. 提醒内容包含：事项、剩余天数、建议动作（还差什么材料/该联系谁）。

## 办理顺序规划（plan 命令的解读）

- 排序规则：截止日期早的在前；同一截止日，材料件数多的优先。
- 启动预留启发式：无材料预留 2 天；有材料预留 `3 + 材料件数` 天，上限 14 天（脚本内置，输出"最迟 X 月 X 日启动"）。
- 输出解读给用户时：先说总览（共几件、几件临期、几件过期），再给"本周该做什么"一句话结论。
- 已过期事项：不静默忽略——提示用户联系对接部门说明情况、询问补报渠道，更新状态或调整新截止日期（`update --id N --deadline ...`）。

## 常用命令速查

```bash
python scripts/ledger_manager.py add --item "奖助学金申报" --deadline 2026-11-30 --dept "资助中心" --materials "申请表、成绩单、个人陈述"
python scripts/ledger_manager.py list            # 未完成
python scripts/ledger_manager.py list --all       # 全部
python scripts/ledger_manager.py upcoming         # 7 天内
python scripts/ledger_manager.py plan             # 办理顺序
python scripts/ledger_manager.py update --id 1 --status "材料准备中"
python scripts/ledger_manager.py done --id 1
python scripts/ledger_manager.py rm --id 1        # 先取得用户确认
```
