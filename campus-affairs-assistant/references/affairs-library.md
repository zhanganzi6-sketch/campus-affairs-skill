# 校务事项知识库（affairs-library）

## 使用规则

1. 每个事项条目含：对接部门、办理渠道、办公地点与工作时间、必备材料、标准流程、风险提示。
2. 【通行做法】= 国内高校普遍流程，可直接引用，但必须提示"以本校最新通知为准"。
3. "本校核实信息总表"中的数据优先于通行做法；表中标注"待核实"的，按通行做法回答并明示待核实。
4. 本校信息核实途径：学校官网（教务处/学工处/后勤处/一站式服务大厅页面）、官方公众号文章、学院网站通知——仅限免登录公开渠道；遇登录墙即放弃该渠道，改为询问用户。
5. 核实到新信息后，回写"本校核实信息总表"对应行（自增长机制），并注明核实日期与来源。

## A01 学生证补办

- **补办时间窗**【学生本人提供 2026-11-20，本校口径】：**每年 5 月、11 月各开放一次补办批次**——错过只能等下一批次；现在正好是 11 月批次期内，如需补办尽快办。
- **对接部门**【通行做法】：教务处学籍管理科（部分学校为学工处或一站式服务大厅）
- **办理渠道**：线上（一站式网上服务大厅/教务系统搜"学生证补办"）或线下（学生服务中心窗口）
- **办公地点/时间**：学生服务中心或行政楼学籍科窗口；通行工作时段为工作日 8:00–12:00、14:00–17:30
- **必备材料**：①学生证补办申请表（本人签名、辅导员或院系签字盖章）②一寸免冠近照 1–2 张（部分学校要求与教务系统照片同底版）③身份证原件及复印件 ④补办工本费约 5–20 元（部分学校免费）
- **标准流程**：挂失（线上平台或窗口）→ 填申请表 → 院系签章 → 提交教务/学工 → 缴费 → 领新证（约 5–15 个工作日）→ 火车票优惠资格重新注册
- **风险提示**：火车票学生优惠需凭新证重新办理优惠卡并加盖注册章；补办期间无法享学生票价；本校每年仅 5 月、11 月两个批次，错过窗口要再等半年——证件遗失应尽早申请，火车票优惠卡需求可与补办一并提出。

## A02 宿舍报修

- **对接部门**【通行做法】：后勤处/宿管中心（学生公寓服务中心）
- **办理渠道**：线上报修平台（后勤报修系统、企业微信、学校公众号"宿舍报修"入口）或电话/宿管值班室
- **必备材料**：无需材料；需宿舍号、故障描述、联系方式、期望上门时段
- **标准流程**：提交报修单 → 后台派单 → 维修工上门（通常 1–3 个工作日）→ 验收评价
- **风险提示**：水管爆裂、断电等紧急故障直接打宿管值班电话，不走线上工单；维修上门前贵重物品收好；公共区域故障也可由舍友共同报修；报修超 3 天未处理可再次催单或向后勤处反映。
- **地球科学学院口径**【已核实 2026-11-20，来源：学院官网表格下载栏】：教学区/实验室/办公室设施故障，学院层面用《地科学院办公室维修单》（2025-11-28 发布，docx 可下载：dqkx.yangtzeu.edu.cn/info/1047/6800.htm），填单交学院办公室（石油科技大楼C118，027-69111650）安排维修；宿舍区报修仍走学校后勤渠道（入口待核实，间辅导员或宿管值班室）。

## A03 奖助学金申报（国家奖学金/励志奖学金/助学金）

- **对接部门**【通行做法】：学生资助管理中心（学工处下属）
- **办理渠道**：班级辅导员组织收集 → 院系初审 → 学校审定；多数学校通过资助系统线上填报
- **常见时间窗**【通行做法】：秋季学期 9–10 月发布通知，10 月前后班级评议与院系报送；国家奖学金评选在前，助学金认定随后——具体日期以本校通知为准
- **必备材料**：①奖助学金申请审批表 ②家庭经济困难认定申请表（助学金类需要）③成绩单/绩点排名证明（奖学金类需要）④个人陈述或申请书 ⑤获奖证书复印件（如有）⑥身份证与银行卡复印件（部分学校要求学校代发卡）
- **标准流程**：看通知确认自身条件 → 领表/线上填报 → 附证明材料 → 班级民主评议 → 院系初审公示 → 学校审定公示 → 发放至银行卡
- **风险提示**：家庭经济情况须真实（虚假申报将取消资格并记录诚信档案）；公示期内有异议机制；银行卡务必用学校指定代发卡且状态正常；错过班级评议截止无法补报。
- **地球科学学院口径**【已核实 2026-11-20，来源：dqkx.yangtzeu.edu.cn/fwzn/gzzd.htm《地球科学学院单项奖学金评定办法》2026-09-02 发布，全文已读】：

  - 申报方法：**个人申报 → 班级汇总上报 → 学院统一审核认定**。
  - 时间窗：优秀集体及个人奖励 **每年 4–5 月或 10–11 月**；考研及就业奖励 **每年 5–6 月**；科创竞赛与文体活动奖励 **每年 6 月及 11 月**汇总评审。

## A04 请假审批（事假/病假）

- **对接部门**【通行做法】：辅导员 → 院系学工办（天数越多审批层级越高，各校分级不同）
- **办理渠道**：请假条纸质流程或学工系统线上审批（各校不同）
- **必备材料**：①请假条/请假申请表（注明事由、起止时间、去向、联系方式）②病假附医院诊断证明/病历 ③事假酌情附佐证（如家里事项证明）
- **标准流程**：先向辅导员口头/线上报备 → 正式填写请假条 → 辅导员签字 → 按天数报院系/学生处审批 → 离校 → 返校后销假
- **风险提示**：务必"先批后离校"，未批擅自离校按旷课处理；病假期间保留挂号单与诊断书；销假逾期同样计违纪；一学期累计请假天数可能影响评奖评优，以本校学籍管理规定为准。

## A05 外出实习报备

- **对接部门**【通行做法】：院系教学办/实习指导教师 + 辅导员双线
- **办理渠道**：院系实习管理系统或纸质报备表；集中实习由学院统一办理，自主实习需个人报备
- **必备材料**：①外出实习报备表/申请表 ②实习单位接收证明（offer 或接收函复印件）③家长知情同意书（部分学校要求）④安全责任承诺书 ⑤实习协议复印件（如有）

- **风险提示**：未报备擅自离校，期间发生事故保险与责任认定易出问题，且可能影响实习学分认定；实习时间与课程/考试冲突要先与教学办协调；跨市实习涉及住宿与安全信息务必如实填写。

## A06 经费报销（班费/社团/竞赛/科研差旅）

## A11 转专业申请

- **对接部门**【通行做法】：教务处牵头 + 目标院系考核
- **常见时间窗**【通行做法】：多数学校在大一下学期（4–6 月）受理，部分学校大一末或大二初，以本校通知为准
- **必备材料**：①转专业申请表 ②成绩单/绩点排名证明 ③个人陈述（转出原因、目标专业认知、学业规划）④目标院系考核（笔试/面试）通知材料
- **标准流程**：关注教务处转专业通知 → 对照条件（常要求无挂科、排名区间）→ 提交申请 → 资格审查 → 目标院系考核 → 拟转名单公示 → 办理学籍异动与学分认定
- **风险提示**：名额有限竞争激烈，提前了解目标院系接收名额与考核形式；转出原因表述要建设性，不贬低原专业；已修学分按规则认定，部分需补修；转专业常影响宿舍与班级调整，做好衔接。
