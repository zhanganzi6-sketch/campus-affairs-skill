# 校务小管家 campus-affairs-assistant

基于 TeleAgent 的校园办事技能包：一句话提出需求，自动完成 **查流程 → 写材料 → 记时间** 链式闭环，让校园办事少跑腿、少翻通知。

## 功能

- **校务事项查询**：学生证补办、宿舍报修、奖助学金申报、请假审批、外出实习报备、经费报销、实验室准入、盖章申请、在读/成绩证明等，返回办理渠道、对接部门、工作时间、材料清单、办理流程
- **办事文书生成**：申请表、请假条、报备表、申请书、承诺书等初稿，填空式模板
- **事项台账与截止提醒**：登记待办校务与截止时间，临期提醒、办理顺序规划
- **知识库自适应**：内置长江大学/地球科学学院已核实口径，其他学校首次使用时询问学校并持续核实回写，越用越准

## 安装

1. 下载 `campus-affairs-assistant.skill`
2. 在 TeleAgent 中导入该技能文件并启用
