# 校务小管家 campus-affairs-assistant

> **当前版本：v1.4**（2026-11-20）｜更新日志见文末

基于 TeleAgent 的校园办事技能包：一句话提出需求，自动完成 **查流程 → 写材料 → 记时间** 链式闭环，让校园办事少跑腿、少翻通知。

## 功能

- **校务事项查询**：学生证补办、宿舍报修、奖助学金申报、请假审批、外出实习报备、经费报销、实验室准入、盖章申请、在读/成绩证明、退宿办理、借教室等（A01–A14），返回办理渠道、对接部门、工作时间、材料清单、办理流程
- **办事文书生成**：申请表、请假条、报备表、申请书、承诺书等初稿，填空式模板
- **事项台账与截止提醒**：登记待办校务与截止时间，临期提醒、办理顺序规划
- **知识库自适应**：内置长江大学/地球科学学院（武汉校区）已核实口径，其他学校首次使用时询问学校并持续核实回写，越用越准

## 安装（TeleAgent 用户）

**方式一（推荐）**：点击仓库根目录的 [`campus-affairs-assistant.skill`](campus-affairs-assistant.skill) 文件 → Download 下载，在 TeleAgent「我的技能」页面上传导入，即装即用。

**方式二**：把本仓库链接发给你的 TeleAgent，说"从 GitHub 安装这个技能"，由智能体代为拉取安装。

## 安装后如何更新

重新下载仓库根目录最新的 `campus-affairs-assistant.skill`，再次导入覆盖旧版即可；导入后打开技能查看 SKILL.md 开头的 `metadata.version`（与本页"当前版本"一致即为最新）。

## 说明

- 仅使用公开免登录渠道核实学校信息，不代提交、不代缴费、不保存账号密码
- 本校细节未核实时明示"待核实，以官方通知为准"
- 时间批次类信息（补办批次、评审窗口）以学校最新通知为准
